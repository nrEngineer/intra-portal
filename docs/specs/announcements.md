# Spec: お知らせ・ニュース機能

## Example Map

- Story: 社員として、社内のお知らせ・ニュースを閲覧・管理したい
- Rules: 12
- Examples: 15
- Questions: 0

## Rules

- R1: お知らせには「タイトル」「本文」「カテゴリ」「公開日」「作成者」がある
- R2: カテゴリは「全社」「部署」「IT」「総務」「その他」から選択
- R3: お知らせ一覧は公開日の新しい順に表示される
- R4: 管理者のみお知らせの作成・編集・削除ができる
- R5: 一般社員はお知らせの閲覧のみ可能
- R6: 重要なお知らせはピン留め（上部固定）できる
- R7: 一覧はページネーション（1ページ10件）で表示
- R8: お知らせは「下書き」「公開」の状態を持つ。下書きは作成者と管理者のみ閲覧可能
- R9: お知らせにはファイル（PDF等）を添付できる。ファイルは Cloudflare R2 に保存
- R10: キーワード検索でタイトル・本文からお知らせを検索できる
- R11: 各社員のお知らせ既読/未読状態を管理し、未読バッジを表示する
- R12: 添付ファイルは最大2個、各10MBまで
